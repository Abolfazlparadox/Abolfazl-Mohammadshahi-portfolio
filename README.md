# Abolfazl Mohammadshahi — Software Engineering Portfolio

A fast, minimalist, and responsive developer portfolio site built with modular Vanilla HTML5, CSS Custom Properties (Tokens), and JavaScript ES6+.

## Stack Architecture
- **HTML5**: Semantic tags, WCAG AA accessibility compliance.
- **CSS3**: Tokens (`tokens.css`), Base (`base.css`), Layout (`layout.css`), Components (`components.css`), Responsive Media Queries (`responsive.css`).
- **Vanilla JavaScript**: Modular JS architecture (`theme.js`, `data.js`, `render.js`, `nav.js`, `reveal.js`, `main.js`).
- **Data**: JSON structured content in `assets/data/*.json`.

## How to Run & Preview
You can serve the static directory using any local web server:
```bash
python3 -m http.server 8000
```
Then open `http://localhost:8000` in your web browser.
